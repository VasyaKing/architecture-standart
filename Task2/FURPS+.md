| Код | Требования                                                                                                                                                             | Комментарий |
|-----|------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------|
| F   | Функциональные (Functionality)                                                                                                                                         |             |
| F1  | На сайте список доступных депозитов с актуальными ставками                                                                                                             |             |
| F2  | Клиент может подать заявку на депозит, оставив свой номер телефона и Ф. И. О                                                                                           |             |
| F3  | В интернет-банке клиент видит список доступных депозитов с актуальными ставками и персонализированные ставки лично для него                                            |             |
| F4  | Указав счёт и сумму депозита, клиент интернет банка может подать заявку на открытие депозита                                                                           |             |
| F5  | Операцию открытия депозита необходимо будет подтвердить с помощью СМС-кода                                                                                             |             |
| U   | Удобство использования (Usability)                                                                                                                                     |             |
| U1  | Нужно придерживаться системы дизайна для приложений, которая принята в компании                                                                                        |             |
| R   | Надёжность (Reliability)                                                                                                                                               |             |
| R1  | Все сервисы должны работать 24/7 и быть доступны в 99,9% случаев                                                                                                       |             |
| R2  | Предусмотреть равномерное горизонтальное масштабирование и распределение запросов между серверами, приложениями и ЦОД                                                  |             |
| P   | Производительность (Performance)                                                                                                                                       |             |
| P1  | Отклик по всем операциям должен быть максимально быстрым и занимать миллисекунды                                                                                       |             |
| S   | Поддерживаемость (Supportability)                                                                                                                                      |             |
| S1  | Предусмотреть разработку документации для дальнейшего расширения системы                                                                                               |             |
| S2  | Нужно как можно больше использовать технологии, которые уже есть в банке                                                                                               |             |
| +R  | + Ограничения (Restrictions)                                                                                                                                           |             |
| +R1 | Данные с сайта необходимо защищать с помощью механизма шифрования трафика                                                                                              |             |
| +R2 | В интернет-банке данные при передаче также надо защитить каким-то механизмом шифрования.                                                                               |             |
| +R3 | Ставки по депозитам сейчас не ведутся нигде, кроме XLS-файлов - с ними должны иметь возможность работать сотрудники бэк-офиса депозитов и кредитов                     |             |
| +R4 | Необходимо перейти на использование микросервисной архитектуры, чтобы снизить дополнительную нагрузку на существующие системы и уйти от зависимости с внешним вендором |             |
| +R5 | Использовать кафка для асинхронных операций - уже сразу пригодится для возможности повторной отправки оповещений клиентам                                              |             |
